# 项目介绍
一项基于 Go 语言构建的视频社交类后端服务项目，涵盖用户管理，视频操作，社交互动，行为交互，聊天等功能，内接AI聊天，同时集成JWT认证等安全机制。
# 技术栈
- **核心语言：** Go
- **接口定义：** Thrift
- **web框架：** Hertz
- **agent框架:** Eino
- **数据库：** MySQL
- **缓存：** Redis
